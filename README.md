## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Full Boss List** | Tracks all vanilla and modded bosses in defeat order |
| **Spawn Info** | Shows exact spawning conditions and required items for each boss |
| **Loot Preview** | View complete drop tables before challenging a boss |
| **Mod Integration** | Other mods can register their bosses via the Boss Checklist API |
